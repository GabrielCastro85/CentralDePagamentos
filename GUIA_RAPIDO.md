# Guia Rápido — Central de Pagamentos

> Rotina diária em formato checklist. Use este guia para não esquecer nada.

---

## Início do dia

- [ ] Abrir o app (o backup automático já foi feito)
- [ ] Conferir o **Dashboard Operacional** — há operações atrasadas ou com saldo negativo?
- [ ] Verificar alertas em vermelho (🔴 saldo negativo) e amarelo (🟡 pendências)

---

## Quando o cliente manda o PIX

1. [ ] Clique em **Nova operação** (canto superior direito)
2. [ ] Preencha: data, cliente, empresa/conta, valor recebido
3. [ ] Confirme — o app abre o detalhe da operação automaticamente

---

## Quando a lista de pagamentos chegar (WhatsApp)

1. [ ] Abra a operação (clique no código ou no nome do cliente)
2. [ ] Clique em **Importar lista**
3. [ ] Copie as mensagens do WhatsApp e cole no campo de texto
4. [ ] Clique em **Detectar pagamentos**
5. [ ] Revise as linhas com ⚠ amarelo — edite o que estiver errado
6. [ ] Verifique: nome, chave PIX/dados bancários, valor, tipo (PIX ou Conta)
7. [ ] Clique em **Importar**

> Se preferir, cadastre um por um clicando em **Novo pagamento**.

---

## Na hora de pagar (no banco ou celular)

Antes de cada pagamento, confira no app:
- [ ] Nome do favorecido bate com o que está na lista?
- [ ] Valor correto?
- [ ] Chave PIX ou conta bancária correta?

Depois de pagar:
- [ ] No app, clique no ✓ verde do favorecido para marcar como **Pago**
- [ ] Acompanhe o saldo da operação — ele deve ficar em R$ 0,00 ou positivo

---

## Após enviar o comprovante

- [ ] Clique no ✉ (ícone de envio) para marcar comprovante como **Enviado**

---

## Para concluir uma operação

1. [ ] Todos os pagamentos marcados como **Pago**?
2. [ ] Todos os comprovantes marcados como **Enviado**?
3. [ ] Saldo zerado ou positivo?
4. [ ] Clique em **Concluir operação** → **Confirmar conclusão**

---

## Final do dia

- [ ] Conferir se há operações em aberto que precisam de atenção
- [ ] O app gera backup automático ao fechar — basta fechar normalmente

---

## Resumo dos status de operação

| Ícone | Status | O que significa |
|-------|--------|----------------|
| ⏳ | Aguardando lista | Operação criada, sem pagamentos ainda |
| 🔄 | Em andamento | Há pagamentos ainda não pagos |
| ✉ | Aguardando comprovantes | Todos pagos, mas faltam comprovantes |
| ✅ | Concluída | Tudo certo — operação no Histórico |

---

## Atalhos úteis

| O que fazer | Como fazer |
|-------------|-----------|
| Nova operação | Botão "Nova operação" (canto superior direito) |
| Ver operação no detalhe | Clicar no código (ex.: OP0001) na tabela |
| Buscar operação | Campo de pesquisa na tela Operações |
| Ver histórico completo | Aba "Histórico" no menu lateral |
| Fazer backup manual | Aba "Backup" → Exportar backup JSON |
| Ver configurações | Aba "Configurações" no menu lateral |
